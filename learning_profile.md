# Learning Profile

## Learner
- Native language: Japanese
- Lives in Australia and has done so for about 20 years
- English is strong enough for everyday and professional life, but several recurring grammar and expression weaknesses remain

## Priority areas
1. Articles and prepositions, especially:
   - a / an / the
   - at / in / on
2. Countable vs uncountable nouns
3. Tense control
4. Describing things naturally and precisely
5. Sentence structure
6. Any additional recurring weaknesses identified through lessons and tests

## Interests for lesson content
- gardens
- productive gardens
- permaculture
- self-sufficient living
- food growing
- soil and compost
- seasonal growing
- sustainable homes
- practical low-impact living

## Teaching preferences
- Adult, practical, natural English rather than textbook-style material
- Reading content should be based on fresh web sources but synthesised, not copied
- New or difficult vocabulary should include Japanese meanings
- Prefer app-native interactive vocabulary UI when it is actually supported
- Do not use raw HTML such as `<details>`, `<summary>`, `<abbr>` or other unsupported tags in ChatGPT messages; these may render literally in the app
- If native tap/hover vocabulary UI is unavailable, use clean plain-text or Markdown fallback formatting rather than pretending the words are interactive
- Tests should be interactive and varied
- Sometimes use image-based description tasks
- Do not reveal test answers before completion
- After a test, provide answers in a copy-friendly format for follow-up review
- Recycle vocabulary and recurring grammar points over time
- Increase difficulty gradually as performance improves
- Track both weak points and improvements
