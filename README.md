# Saori's English Learning

This repository is the persistent learning record for Saori's daily English practice with ChatGPT.

## Schedule
- Daily session at **8:00 am Australia/Melbourne time**.
- First scheduled session: **Reading**.
- On weekdays, alternate between **Reading** and **Test** sessions.
- **Saturday and Sunday are always Reading days**; never schedule a test on weekends.
- Weekend readings do not consume or flip the weekday Reading/Test sequence.

## Topics
Readings should draw on fresh web material and Saori's interests, especially:
- gardening
- productive gardens
- permaculture
- self-sufficient living
- food growing
- composting and soil
- seasonal growing
- sustainable homes and practical low-impact living

## Learning goals
Prioritise:
- articles and prepositions, especially `a/an/the` and `at/in/on`
- countable vs uncountable nouns
- tense control
- descriptive English
- sentence structure
- additional weak points discovered over time

## Session design
### Reading days
Create an engaging, adult, level-appropriate reading synthesised from fresh web sources. Use the **Chappie workspace app** for the interactive reading UI when callable. Vocabulary likely to be unfamiliar should reveal a Japanese meaning on hover/click. If Chappie is unavailable in a run, state that limitation clearly rather than pretending the interaction exists. Include light comprehension or language-noticing prompts without turning the reading into a formal test.

### Test days
Use **Chappie** for interactive exercises with input fields and multiple-choice answers when callable. Test recent readings, recycled vocabulary, and known weak points. Vary the exercise style. Sometimes use a relevant image, short visual, object, scene, place, or artwork and ask Saori to describe an aspect of it in English.

Do not reveal test answers before completion. After completion, show the answers and also provide them in a copy-friendly format so Saori can paste them back into chat for review and explanation.

## Repository files
- `learning_profile.md` — stable learner profile and teaching instructions
- `state.md` — current Reading/Test sequence state
- `vocabulary.md` — running vocabulary record
- `progress.md` — weak points, corrections, and improvements over time
